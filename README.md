# sistema_anotacao_senai
Sistema para fazer anotações no SENAI:

O sistema deve ser utilizado para anotações do Senai, que são infrações ao regulamento senai

Cadastro:
Nome
Número
Sala
Gravidade
Motivo
Data e hora
Foto/print (opcional)

O cadastro deve ter a funcionalidade CRUD (criar, listar, concluir/atualizar, excluir).
